# SASjs Server documentation

The source of <https://server.sasjs.io>, built with MkDocs Material and published from `main`.

- **Read the docs:** <https://server.sasjs.io>
- **Build them locally, or contribute:** see [README.txt](README.txt) for the pinned toolchain, the local build and the two documentation checks CI runs.

Pages live in `docs/`, the navigation and theme in `mkdocs.yml`. Deployment is automatic when a change reaches `main`; the scorecard badge above comes from `.github/workflows/scorecard.yml`.
